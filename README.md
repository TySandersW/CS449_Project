This project entails creating a Peg Solitaire BrainVita game. It is a single player board game, where the player jumps pegs over adjacent ones, removing the jumped pegs. 

The game is filled with pegs besides a central hole which is empty. The player makes moves and aims to empty the entire board except for one remaining peg. A valid move for a player is to jump a peg orthogonally or diagonally over an adjacent peg into a hole two positions away, then removing the jumped peg.
